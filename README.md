# easydoc

基于 Docx4j 和多种模板引擎实现的 Word 快速输出组件。

## Maven

```xml
<dependency>
  <groupId>io.github.easy4j</groupId>
  <artifactId>easydoc-core</artifactId>
  <version>${easydoc.version}</version>
</dependency>
```

按需引入引擎模块，例如 `easydoc-freemarker`、`easydoc-thymeleaf`、`easydoc-beetl`、`easydoc-velocity`、`easydoc-xhtml` 等。
